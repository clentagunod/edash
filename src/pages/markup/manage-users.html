Replace mode: replace E-Dash-managed school data

Imported documents overwrite matching records. Other E-Dash-managed records missing from the file are deleted, leaving the app-managed data to match the backup.

This browser tool only works with E-Dash-managed Firestore paths. It does not erase the entire Firestore database: Firebase Authentication accounts and unrelated/custom collections are not included. A safety JSON copy is downloaded first, but restore is not atomic and an interruption may leave a partial restore.

Only continue with a trusted backup for this school and the matching database schema. Keep the downloaded safety copy until you have verified the restored data.
